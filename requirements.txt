# NOTE ON GDAL
# ------------
# `pip install GDAL` builds from source and needs the GDAL C++ SDK plus a
# matching compiler. On Windows it fails out of the box. `rasterio` ships
# prebuilt wheels that bundle their own GDAL, which is all Phase 0 needs, so
# GDAL is NOT pinned here as a hard requirement.
#
# If you need the standalone GDAL Python bindings and CLI (gdalwarp,
# gdal_translate, ...), install them through conda instead:
#     conda install -c conda-forge gdal
# or on Linux via the system package manager, then:
#     pip install GDAL=="$(gdal-config --version)"
